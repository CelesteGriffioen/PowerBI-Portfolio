# 📊 Dashboard de Ventas en Power BI

## Descripción

Este proyecto consiste en el desarrollo de un dashboard interactivo en Power BI para el análisis de ventas de distintos productos a lo largo del tiempo y en diferentes regiones.
El objetivo del reporte es facilitar la exploración de la información mediante visualizaciones dinámicas, filtros interactivos y herramientas de navegación que permitan profundizar el análisis sin sobrecargar la vista principal.

---

## Objetivos del dashboard

- Analizar la evolución de las ventas en el tiempo.
- Comparar el desempeño de los distintos productos.
- Analizar las ventas por región.
- Explorar la información mediante filtros interactivos.
- Navegar entre un resumen ejecutivo y una vista detallada utilizando Drill-through.

---

## Funcionalidades implementadas

- Indicadores (KPI)
- Gráfico de líneas
- Gráficos de barras
- Gráfico circular
- Tabla de detalle
- Segmentadores (Slicers)
- Tooltips
- Drill-through
- Navegación entre páginas
- Visualizaciones interactivas

---

## Estructura del reporte

### Página 1 – Resumen Ejecutivo

Incluye indicadores generales, evolución temporal de las ventas, comparación por producto, análisis por región y filtros interactivos.

### Página 2 – Detalle del Producto

Presenta un análisis específico del producto seleccionado mediante Drill-through, incluyendo gráficos adicionales y una tabla con el detalle de las ventas.

---

## Dataset

El conjunto de datos fue proporcionado como parte de una actividad académica e incluye las siguientes variables:

- Fecha
- Región
- Producto
- Cantidad
- Ventas
