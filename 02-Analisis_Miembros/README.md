# 📊 Dashboard de Análisis de Asistencia y Miembros

## Descripción

Este proyecto consiste en el desarrollo de un dashboard interactivo en Power BI para el análisis de indicadores relacionados con asistencia y composición de miembros de una congregación.

El reporte fue construido a partir de dos conjuntos de datos proporcionados para el proyecto. Debido a que contienen información privada, los archivos originales no se incluyen en este repositorio.

---

## Objetivos

El dashboard permite:

- Analizar la evolución de la asistencia a lo largo del tiempo.
- Identificar valores máximos, mínimos y promedio de asistencia.
- Visualizar indicadores generales sobre los miembros de la organización.
- Analizar la distribución por estado, género, grupos y áreas de servicio.
- Facilitar la exploración de la información mediante visualizaciones interactivas y filtros.

---

## Herramientas utilizadas

- Power BI Desktop
- DAX
- Power Query
- Excel (como fuente de datos)

---

## Funcionalidades implementadas

- Indicadores (KPI)
- Gráficos de líneas
- Gráficos de barras
- Gráfico de dona
- Treemap
- Tabla de detalle
- Línea de referencia
- Visualizaciones interactivas
- Modelado de datos con múltiples tablas y relaciones

---

## Estructura del reporte

### Página 1 – Análisis de Asistencia

Incluye indicadores generales de asistencia, evolución temporal, línea de referencia para comparar la cantidad de asistentes activos y una tabla con el detalle de cada reunión registrada.

### Página 2 – Análisis de Miembros

Presenta indicadores generales sobre los miembros de la organización y visualizaciones para analizar la distribución por estado, género, áreas de servicio y grupos.

---

## Modelo de datos

El reporte utiliza un modelo relacional compuesto por múltiples tablas conectadas mediante relaciones, incluyendo tablas puente para representar relaciones de muchos a muchos cuando fue necesario.

---

## Dataset

Los datos utilizados fueron proporcionados para este proyecto y contienen información privada.

Por motivos de confidencialidad, los archivos de origen no se incluyen en este repositorio.
